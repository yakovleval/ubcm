# Состояние реализации

Выполнены:

- битовое хранилище, кодеки, четыре режима адресации;
- глобальные регистры и разрешение локальных имён в глобальные адреса;
- активации в регистрах, обход цепочки, обнаружение циклов;
- встроенные команды, вычисления, префиксы, вызовы и возвраты;
- РС-резолверы локальных, сверхлокальных и глобальных имён в read-only режиме;
- атомарный шаг и ограниченный по шагам/глубине запуск;
- контейнер v2, отдельный файл процедуры, загрузчик, CLI и пример;
- модульные и интеграционные тесты, детерминированные случайные проверки кодеков.

РС-резолвер возвращает адрес через `RESOLVE_RETURN` (`1110`). Попытки записи
запрещены; временное состояние интерпретатора отбрасывается. Протокол описан
в `resolvers.md`. Таблицы имён остаются запасным механизмом при нулевой ссылке
на РС-резолвер.

Формат файлов и команды запуска описаны в `specification-v2.md` и `running.md`.
Это исходные регистры программы, а не сохранение работающей VM со стеком.
